Running a 5ire validator node allows you to participate in the network, contribute to its security and decentralization, and be eligible for the 5M $5IRE Validator’s Airdrop . This step-by-step guide will walk you through the entire process of participating in the pre-mainnet campaign. Step 1: Minimum Requirements To run a validator node, you need to have at least 100,000 $5IRE tokens stored in any supported wallet on the Ethereum Mainnet.
